# KOTA AEROSPACE — M11 CUSTOMER REQUIREMENTS REGISTER

## Prospect: Horizon Regional Air & Drone Mobility ("Horizon Air")

---

### Classification Legend
- **SUPPORTED**: Directly satisfied by existing KOTA core services (M5–M10).
- **CONFIGURATION**: Satisfied by standard platform configuration and data mapping.
- **MINOR ENHANCEMENT**: Low-effort UI or schema tweak without core domain restructuring.
- **EXTERNAL INTEGRATION**: Requires customer or third-party API adapter.
- **DATA MIGRATION**: Resolved via M5 Import Center pipeline.
- **NOT SUPPORTED**: Outside current product boundary.
